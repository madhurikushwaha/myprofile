# Madhuri Kushwaha — Portfolio

Responsive personal portfolio website for a Web Developer specializing in PHP, WordPress, Shopify and Laravel.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — responsive design and styling
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## Customize before publishing
1. Replace the contact email in `index.html` with your preferred email.
2. Add your phone number or LinkedIn link if you want them public.
3. Confirm the experience dates and descriptions.
4. Add screenshots of projects if you have permission to publish them.
5. Upload the files to the root of your `myprofile` repository and commit/push.

Project descriptions are written to describe contribution areas without claiming sole ownership of employment projects.
